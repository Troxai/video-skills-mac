# social-video — skill cho Claude Code

Cài: `unzip social-video.skill -d ~/.claude/skills/` (tạo `~/.claude/skills/social-video`).
Lần đầu: mở `claude` trong `~/goc-nhin` (tạo thư mục trước) và gõ `/social-video setup`.
Sau đó: `/social-video all goc-nhin-da-chieu` để chạy thử trọn quy trình; cron dùng `config/crontab.txt`.

Nội dung: SKILL.md (quy trình), reference/ (style, script, factcheck, images, publish),
scripts/ (TTS VieNeu, tách nền, nhạc, Muse, đăng YouTube/Facebook/TikTok, Telegram),
assets/template (Remotion + tập mẫu FPT đã duyệt + thư viện ảnh), assets/channels, assets/config.
